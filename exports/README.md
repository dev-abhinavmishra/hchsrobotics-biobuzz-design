# Exports — sprint-04 (as-built)

Generated by `scripts/freecad/export_step.py`,
`scripts/freecad/make_drawings.py`, `scripts/freecad/render_png.py`, and
the `selfcheck_overhaul0{1,2,3}.py` gate transcripts (rerun after any
rebuild). All artifacts derive from the parametric FreeCAD model —
FreeCAD is the source of truth; these files are read-only derivatives.

## Layout

| Path | Contents |
|---|---|
| `step/parts/<NAME>.step` | One AP203 STEP per exportable solid (1089 files). PRODUCT records carry the FreeCAD object names — reimported parts come back named, not anonymous Part__Feature blobs. Each is positioned by its object's global placement — import matches the FCStd exactly. |
| `step/subassembly/*.step` | Assembly-group STEP files (GRP_DRIVEBASE, GRP_FRAME, GRP_PODS, GRP_ELECTRONICS, GRP_INTAKE, GRP_HOPPER, GRP_TURRET, GRP_TURRET_ROT, GRP_LIFT, GRP_FASTENERS) plus subsystem slices (`drivebase.step`, `electronics.step`, `intake.step`, `hopper.step`, `turret.step`, `lift.step`). |
| `step/master_robot.step` | The complete master assembly in one STEP. Reimported and solid-counted as part of the export gate. |
| `drawings/` | Engineering-drawing output from `make_drawings.py`: one A4-landscape sheet per unique part (580 sheets) as PDF + SVG with TOP/FRONT/RIGHT views, overall-dimension callouts and a title block, plus flat R12 DXF profiles in `drawings/dxf/` for the 165 plate-like parts. See `drawings/README.md`. |
| `bom/bom.csv` | Bill of materials aggregated across subsystem BOM rows — subsystem, description, material, spec, status, qty, object list. |
| `parameters.csv` | Every `Parameters` spreadsheet alias: value, unit, status, source note. Mirrors `docs/robot-parameters.md`. |
| `mount_graph.json` | The declared pair tables: joints (members + bolts + nuts), faces, embeds, journals, contacts, ground census, BOM rows — what GEO/FAST gates verify. |
| `meta/<tag>.json` | Same pair tables per document (drivebase / electronics / intake / hopper / turret / lift / master). |
| `renders/*.png` | Shaded orthographic previews (`render_png.py`): front/side/top/iso per document, subsystem palette. |
| `selfcheck_overhaul0{1,2,3}.txt` | Latest gate transcripts (45, 61 and 73 gates respectively — all PASS). |

## Status labels

Every exportable solid name/label carries a status suffix:
`_VERIFIED` (manual-cited), `_VENDOR-PENDING` (goBILDA-catalog, awaiting
datasheet), `_UNVERIFIED` (assumed). Construction intermediates are
`TOOL_`-prefixed with unique status-bearing labels so no solid exports
an unlabeled or duplicated label (PROV1/PROV2 gates).

## Notes

- The ball route: intake mouth → inclined hopper floor → feed wheel →
  clear column bore → metering gate → turret launcher (POLLEN into the
  HIVE cell), or — with the Y-flap diverter — out the `COL_PORT`
  window → `PORT_FLANGE` → two-leg LOAD_CHUTE → lift cradle → FLOWER
  mouth (NECTAR).
- The yaw drive is an external ring mesh: 72T ring on the turret's
  outer rim driven by a 14T pinion at 72.8 mm centre distance, yaw
  servo mounted at −Y of the turret axis under the deck.
- The lazy-susan Z-stack is resolved bottom-up: deck 244–248 mm,
  susan races 248–256.5 mm, ring gear 256.5–263 mm, plate 263–267 mm.
- The load chute is two legs (28.5° and 21.8°) from the column port to
  the cradle's Ø99 mm park bore at z ≈ 140 mm.
- The electronics expansion hub sits on the right frame rail outer
  face (|y| ≈ 200 mm).
- Values marked UNVERIFIED/VENDOR-PENDING are placeholders pending
  measurement or datasheet confirmation — see
  `docs/robot-parameters.md` before manufacturing.
- The frame footprint is 444.5 mm square; enumerated fastener classes
  protrude up to ~3 mm into the start-cube margin.
- Older deliverables live under `../cad/archive/` (pre-overhaul FCStds)
  and `../scripts/freecad/legacy/` (concept scripts).
