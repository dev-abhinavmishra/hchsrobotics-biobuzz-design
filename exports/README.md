# Exports — sprint-02

Generated by `scripts/freecad/export_step.py` (rerun after any rebuild).
All artifacts derive from the parametric FreeCAD model — FreeCAD is the
source of truth; these files are read-only derivatives.

## Layout

| Path | Contents |
|---|---|
| `step/parts/<NAME>.step` | One AP203 STEP per exportable solid (772 files; the WHEEL_ASSY carriers + tool/probe objects are document-internal). PRODUCT records carry the FreeCAD object names — reimported parts come back named, not anonymous Part__Feature blobs. Each is positioned by its object's global placement — import matches the FCStd exactly. |
| `step/subassembly/GRP_*.step` | Assembly-group STEP files (GRP_DRIVEBASE, GRP_FRAME, GRP_PODS, GRP_ELECTRONICS, GRP_INTAKE, GRP_HOPPER, GRP_FASTENERS + subsystem slices `drivebase.step`, `electronics.step`, `intake.step`, `hopper.step`). |
| `step/master_robot.step` | The complete master assembly in one STEP. Reimported and solid-counted as part of the export gate. |
| `bom/bom.csv` | Bill of materials aggregated across subsystem BOM rows — subsystem, description, material, spec, status, qty, object list. |
| `parameters.csv` | Every `Parameters` spreadsheet alias: value, unit, status, source note. Mirrors `docs/robot-parameters.md` (sprint-01 + sprint-02 alias tables). |
| `mount_graph.json` | The declared pair tables: joints (members + bolts + nuts), faces, embeds, journals, contacts, ground census, BOM rows — what GEO/FAST gates verify. |
| `meta/<tag>.json` | Same pair tables per document (drivebase / electronics / intake / hopper / master). |
| `renders/*.png` | Shaded orthographic previews (`render_png.py`): front/side/top/iso per document, subsystem palette. |
| `selfcheck_overhaul02.txt` | Latest gate transcript. |

## Status labels

Every exportable solid name/label carries a status suffix:
`_VERIFIED` (manual-cited), `_VENDOR-PENDING` (goBILDA-catalog, awaiting
datasheet), `_UNVERIFIED` (assumed). Construction intermediates are
`TOOL_`-prefixed with unique status-bearing labels so no solid exports
an unlabeled or duplicated label (PROV1/PROV2 gates).

## Sprint-02 notes

- The ball route is the under-crown path: intake mouth → nip → basin →
  inclined lane → feed wheel → `COL_WIN` throat → clear column bore →
  metering gate → `COL_PORT` +Y window → `PORT_FLANGE` (REF_DIV_PORT
  interface at (−66, 56, 204) for the sprint-03 chute).
- The gate servo/bracket live on the **−Y wall**; the +Y corridor is
  reserved for the port sphere. The diverter flap parks below the port.
- Declared embeds now include every real interpenetration the
  `DECL_contacts_real` gate measures with `common().Volume`: chain↔
  sprocket mesh, belt↔pulley/idler wraps, clamp-band shrink fit, spur
  tooth mesh, wire-bundle loom, apron↔floor lap, spring leg roots.
- Values marked UNVERIFIED/VENDOR-PENDING are placeholders pending
  measurement or datasheet confirmation — see
  `docs/robot-parameters.md` before manufacturing.
- Sprint-03 mechanisms (turret/shooter, lift, camera, USB loom) are
  intentionally absent; REF_*/AXIS_* datums mark the interfaces.
- The frame footprint is 444.5 mm square; enumerated fastener classes
  protrude up to ~3 mm into the start-cube margin (span 453.7 x
  454.5 mm, >=2 mm margin).
- Older deliverables live under ../cad/archive/ (pre_overhaul FCStds)
  and ../scripts/freecad/legacy/ (concept scripts).
