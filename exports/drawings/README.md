# exports/drawings/

Engineering-drawing output, generated by
`freecadcmd scripts/freecad/make_drawings.py` (see that file's docstring
for the environment-variable selectors).

- `<doc>_<part>.svg` / `<doc>_<part>.pdf` — one A4-landscape sheet per
  unique part (identical instances are grouped and shown as QTY): TOP,
  FRONT and RIGHT-SIDE views, overall extent-dimension callouts on each
  view, and a title block (part, material, spec, qty, rev, scale).
- `dxf/<doc>_<part>.dxf` — flat R12 profile for every plate-like part
  (thin+wide geometry, or a plate-hint name such as deck/base/cheek/
  bracket/pan/gusset), face-normal rotated to +Z, origin at the
  bounding-box minimum. Ready for laser/waterjet nesting.
- `manifest.json` — machine-readable per-part report (doc, qty, bbox,
  material, plate flag, output paths).
- `manifest.txt` — the same per-part list as printed on stdout.
- `sample/` — a few representative sheets + DXFs kept in-repo for
  review. The full per-run output (~1,150 sheet files + ~190 DXFs,
  ~140 MB) is gitignored; regenerate it any time with the command
  above.

Regenerate after any geometry change; the part list is enumerated from
the documents, not hardcoded.
